# Pretty Windows

面向 **Windows 11** 的轻量级系统美化与桌面交互工具集，基于 `Rust` 与原生 `Win32` / `Direct2D` / `DirectWrite` / `WinRT` 构建。应用以系统托盘常驻托管各独立模块，可按需自由开关。

---

## 核心功能

### 1. 整体外观联动（5 档质感风格）
提供 **默认 / 透明 / 毛玻璃 / 亚克力 / 液态玻璃（Liquid Glass）** 五档全局风格，自动跟随 Windows 11 深浅主题与透明效果设置，切回「默认」或退出应用时自动恢复原生外观：
- **多显示器任务栏**：统一替换各显示器任务栏底色与材质层次，全屏及任务栏自动隐藏时自动隐退。
- **系统浮窗视觉统一**：同步联动系统托盘溢出栏、`Alt + Tab` 任务切换器卡片、任务栏悬停缩略图预览浮窗、任务栏与托盘悬浮提示胶囊（ToolTip）、快速设置与媒体控制卡片（`Win + A`）、通知中心与日历（`Win + N`）、浮动系统通知（Toast），以及任务栏/应用图标/托盘现代右键菜单与 JumpList（支持多级级联子菜单，全屏/置顶窗口覆盖时自动切换为无阴影内联玻璃效果）。
- **系统硬件 OSD 胶囊**：美化音量、亮度、键盘背光、飞行模式与隐私开关等系统浮窗并保留原有交互；游戏/全屏置顶画面覆盖时自动兼容切换为无阴影内联玻璃效果。

### 2. MediaBar（任务栏媒体控制挂件）
- **实时播放信息与频谱**：基于 `SMTC` 显示当前曲目、歌手与专辑封面，并附带实时音频频谱动态条。
- **快捷交互**：鼠标悬停切换上一首 / 播放暂停 / 下一首控制按钮，支持内联音量滑块、滚轮调音与静音切换。
- **封面自动取色**：支持根据专辑封面提取主题高亮色（自动规避与玻璃底色相近的灰暗色区以保证清晰可读），同时支持无媒体或关闭自动取色时跟随背景色调。
- **级联菜单**：右键可切换播放源、调整分应用音量混音器、切换默认播放 / 录音设备。

### 3. MonitorBar（任务栏系统监控挂件）
- **实时硬件指标**：在任务栏紧凑展示上传/下载网速、CPU、内存、显卡与硬盘使用率，支持高负载视觉提醒与按需显示/隐藏监控列。
- **快捷控制菜单**：右键菜单集成 `Wi-Fi` 与蓝牙开关/设备连接、多显示器独立亮度调节（支持 `DDC/CI` 外接显示器与内置屏幕背光），以及左键单击动作自定义（任务管理器 / 显示桌面 / 系统设置 / 指定程序）。

### 4. 挂件交互与防重叠
- 支持取消锁定后在任务栏自由拖拽定位、随时重置默认位置。
- `MediaBar` 与 `MonitorBar` 开启时具备水平碰撞检测与让位机制，拖拽贴边停靠或跨过中点换边，开启/关闭或增减监控列时互不遮挡。
- 通过系统托盘右键菜单集中控制挂件开关、美化风格切换与开机自启。

## 快速使用

- **系统要求**：Windows 11（64 位）。
- **运行方式**：将 `PrettyWindows.exe` 与 `PrettyWindowsTap.dll` 放在同一目录下，直接运行 `PrettyWindows.exe` 即可（建议同时开启 Windows「个性化 → 颜色 → 透明效果」以获得完整模糊质感）。
- **配置文件**：首次使用后会在程序同目录自动生成 `Taskbar.toml`、`MediaBar.toml` 与 `MonitorBar.toml`。

## 从源码构建

### Windows 本机环境（MSVC 工具链）
```bash
cargo build --workspace --release
```
构建产物位于：
- `target/release/PrettyWindows.exe`
- `target/release/PrettyWindowsTap.dll`

### Linux / WSL 交叉验证与构建
```bash
# 运行跨平台核心单元测试
cargo test --workspace

# Windows 目标交叉编译检查
cargo check --workspace --target x86_64-pc-windows-msvc

# 交叉构建 Windows Release 二进制（需配置 cargo-xwin）
cargo xwin build --workspace --release --target x86_64-pc-windows-msvc
```
